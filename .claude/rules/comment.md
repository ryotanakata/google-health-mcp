# コメント規約

コメントは「**コードを消しても復元できない情報**」だけを書く。

書く直前に自問する: **このコメントを消して、コードと既存の規約を読んで同じ結論に到達できるか。** 到達できるなら書かない。

コメントが長くなる箇所は、実装に自信がない箇所とほぼ一致する。長い説明が必要になったら、まず命名・分割・早期 return でコード側を直せないか検討する。

## 書くもの

- **隠れた制約** — Google Health API の仕様上の上限・形式（期間上限、pageSize 上限、proto3 JSON の省略規則）、MCP SDK の既定動作、Cloud Run の実行環境、Claude のコネクタ仕様
- **workaround を入れた理由と、外せる条件**
- **読み手が驚く挙動** — 直感に反する分岐、意図的に非効率な実装
- **セキュリティ上の選択理由** — 定数時間比較、エスケープの位置、許可リストの範囲、ステートレスにした代償など、**その選択を知らずに「直す」と弱くなるもの**
- **値の意図・根拠** — 定数の値が名前から分からない場合の根拠（API 仕様、README の該当箇所）

**この節に当たるものは、規約に同じ記述があってもコード側に残す。** 実装から入った読み手が規約に到達しない経路を塞ぐ。

## 書かないもの

- **WHAT** — `# アクセストークンを取得する` / `# 早期 return する`
- **規約で担保済みの内容の言い直し** — 層ごとの責務、依存の向き、命名規則、定数の置き場所など。規約を参照させ、コメントで再掲しない
- **完了した作業の記録** — `追加した` / `旧実装` / `以前は` / `もともと` / `〜に変更` / `当初案は`
- **決着済みの議論の経緯**

## 変更履歴の扱い — 書き直せるなら書き直す、書き直せないなら消す

禁止しているのは「履歴の形式」であって、履歴が運んでいる制約ではない。過去形で書きたくなったら、現在の制約として書き直せるか先に検討する。

```python
# NG（記録）
# 以前は SSE だったが Streamable HTTP に変更した

# OK（制約）
# セッションを持たないので、Cloud Run のどのインスタンスに振られても処理できる
```

書き直せない = 現在の挙動に影響しない = 消してよい。

## タスク ID / issue 参照

完了した作業の記録として書くのは NG。**未解決の条件へのポインタは OK**。参照先の状態が変わるとコードの正しさが変わるなら、それは「外せる条件」なので残す。

- NG: `# (GHM-0003) ページングを追加`
- OK: `# SDK 3.0 で validate_token_resource の既定が True になったら（GHM-0012）この指定は不要`

## docstring

- 関数・メソッド・クラスの docstring も本規約の対象。**識別子名とシグネチャ（型注釈）から復元できる要約は書かない**
- Python は引数・戻り値に型注釈を付ける（`python-style.md`）ため、**型注釈で表現できている型を docstring で再掲しない**
- モジュール docstring は、そのモジュールだけが持つ前提（準拠する外部仕様、設計上のトレードオフ）がある場合のみ書く

```python
# NG（識別子名の言い直し）
class HealthApiError(RuntimeError):
    """Google Health APIの呼び出しが失敗したときに送出する。"""

# OK（名前から分からない前提）
def _duration_minutes(value: str | None) -> int | None:
    """google.protobuf.Duration の JSON 表現（"3600s", "90.5s"）を分に変換する。"""
```

## 対象外（この規約は適用しない）

- **MCP ツール関数の docstring** — `@mcp.tool()` の docstring はツールの説明として Claude に送られる実行時データ。WHAT でも保持する（`mcp-tools.md`）
- **抑制コメントの理由注記** — `# noqa: E501 -- 理由` / `# type: ignore[...] -- 理由`
- **`TODO` / ライセンスヘッダ**
- **ユーザーに表示する文言** — 同意画面の HTML・エラーメッセージの文字列はコメントではない

## 例

```python
# NG（WHAT）
# 1日分の範囲を作る
body = {"range": {...}, "windowSizeDays": 1}

# OK（隠れた制約）
# exercise・sleep の list は pageSize の上限が25
SESSION_PAGE_SIZE = 25
```

```python
# NG（規約で担保済みの言い直し）
# service は repository を経由して API を呼ぶ
points = await self._repository.fetch_sleep_sessions(day)

# OK（セキュリティ上の選択理由）
# 認可コードの再利用防止。インスタンスをまたぐと効かないが、PKCE と5分の有効期限で補う
self._used_codes: dict[str, float] = {}
```

## 既存コメント

変更範囲内のコメントのみ規約に合わせる。**触っていない行のコメントは削除しない。** ただし docstring は行ではなく**関数・クラス単位**で揃える。

**コメント削除だけを目的とした差分を、機能変更の PR に混ぜない。**

## ドキュメント

| 対象 | 方針 |
|---|---|
| `CLAUDE.md` / `README.md` / `README.ja.md` / `.claude/rules/` | 現在の仕様のスナップショット。経緯・マイグレーション履歴は書かない。「〜だったが〜になった」は結果だけに書き換える。ただし**旧構成・移行対象への言及は、旧コードが残っている間は現在の仕様**として残す |

経緯・変更理由の記録先はコミットメッセージと PR 本文。コード内には残さない。
